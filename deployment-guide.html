📋 Your Deployment Checklist

PHASE 1: Create GitHub Repository

Step 1: Go to https://github.com/new
Step 2: Fill in:
  • Repository name: mf-analysis
  • Description: Indian Equity Mutual Fund Comparison Platform
  • Visibility: Public (important for free tier)
Step 3: Click "Create repository"
✓ Copy your repository URL: It will look like
https://github.com/YOUR_USERNAME/mf-analysis.git

PHASE 2: Push Code to GitHub

Step 1: Open PowerShell in your project folder
Step 2: Copy and paste these commands (one at a time):
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/mf-analysis.git
git push -u origin main
Note: When asked for password, use GitHub Personal Access Token from https://github.com/settings/tokens
✓ Success! You should see "Branch 'main' set up to track remote branch 'main'"

PHASE 3: Deploy Backend on Render

3.1: Go to https://render.com → Sign up with GitHub
3.2: Create PostgreSQL Database
3.3: Create Web Service with your repository
3.4: Add Environment Variables:
KeyValue
DATABASE_URLYour PostgreSQL connection string
CORS_ORIGINShttp://localhost:3000
ENVIRONMENTproduction
3.5: Run migrations: Go to Shell tab and run alembic upgrade head
✓ Backend is live! Your API URL will be shown on Render dashboard

PHASE 4: Deploy Frontend on Vercel

4.1: Go to https://vercel.com → Sign up with GitHub
4.2: "Add New" → "Project" → Select mf-analysis
4.3: Set Root Directory to frontend
4.4: Add Environment Variable:
  • Name: NEXT_PUBLIC_API_URL
  • Value: Your Render backend URL
4.5: Click Deploy and wait
✓ Frontend is live! Your app URL will be shown

PHASE 5: Final Setup

Update CORS on Render:
  • Go to mf-api service → Environment
  • Update CORS_ORIGINS to include your Vercel URL
  • Save changes
✓ Everything is connected!
