TROUBLESHOOTING QUICK REFERENCE
==============================

Problem: "git push fails with authentication error"
Solution: Use GitHub Personal Access Token
         Go to: https://github.com/settings/tokens

Problem: "Render deployment is slow"
Solution: It's normal! Docker build takes 5-10 min first time

Problem: "Frontend shows 'Cannot connect to API'"
Solution: Check CORS_ORIGINS in Render environment variables
         Make sure it includes your Vercel URL

Problem: "Database shows DOWN in health check"
Solution: Go to Render PostgreSQL service
         Check it's still running (should show 'Available')

See DEPLOY_NOW.md for more detailed troubleshooting.
