QUICK START (3 STEPS)
====================

STEP 1: Push to GitHub
-------
Windows: deploy-setup.bat
Mac/Linux: bash deploy-setup.sh

STEP 2: Deploy on Render (5 minutes)
----------
1. https://render.com → Sign up with GitHub
2. Create PostgreSQL database
3. Create Web Service → Deploy this repo
4. Set environment variables
5. Run: alembic upgrade head

STEP 3: Deploy on Vercel (2 minutes)
----------
1. https://vercel.com → Sign up with GitHub
2. Import this project
3. Set root to "frontend"
4. Add NEXT_PUBLIC_API_URL env var
5. Deploy

That's it! Your app is LIVE. Total time: ~15 minutes.

MONTHLY DATA UPDATES
====================

The system automatically:
1. Fetches latest AMFI fund rankings
2. Downloads official AMC portfolio disclosures
3. Parses and validates holdings
4. Updates PostgreSQL with monthly snapshot
5. Generates ingestion report

Schedule options:
- Render Cron: Free, easy, reliable
- GitHub Actions: Free, automated CI/CD
- Manual: Run once per month
